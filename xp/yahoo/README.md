# Yahoo! photographs

The front page's pictures are blank until you drop files in here. Each slot
takes a `.jpg` named after the slot shown on the grey placeholder:

| File | Where it appears | Rough size |
|---|---|---|
| `movie-stealth.jpg` | Yahoo! Movies, left film frame | 118 x 118 |
| `movie-dogs.jpg` | Yahoo! Movies, right film frame | 140 x 118 |
| `ent-blondes.jpg` | Entertainment, "Stars Gone Blonde" | 110 x 82 |
| `buzz-magician.jpg` | Buzz Log, "Master Magician?" | 110 x 82 |
| `market-camera.jpg` | Marketplace, digital camera | 86 x 70 |

Anything you drop in is cropped to fill, so the exact pixel size doesn't
matter — only roughly the right shape. No rebuild needed; just reload.
