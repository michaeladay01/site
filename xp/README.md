# Drop-in wallpaper

Put the real Windows XP wallpaper here as `bliss.jpg` and the desktop will use it
automatically — no code change needed. If the file is absent, the desktop falls
back to the vector recreation drawn in `src/styles/xp.css`.

    a-corner-of-2005/public/bliss.jpg

The photograph is Microsoft's (shot by Charles O'Rear), so keep it out of
anything you publish or sell. Nothing else in this project ships a binary asset.
